# 計算資源・起動方法

## 計算資源

現在のブラウザー版では、量子ウォークの数理モデルを古典計算機上でリアルタイムにシミュレーションしている。

Qartの現在の161×161格子では、各地点に二つの複素振幅を保持するため、約5.2万個の複素振幅を逐次更新する。二進数の位置レジスタとして表現すれば、x座標8量子ビット、y座標8量子ビット、内部状態1量子ビットの計17量子ビットで表現できる。

17量子ビットは状態を表現するための数である。量子コンピュータ実機で処理する場合には、回路や測定に必要な計算資源を別途検討する必要がある。

### 現在の実装

| 処理 | 実行する場所 |
| --- | --- |
| 複素振幅・位相・干渉の計算 | CPU |
| 光・花・残光の描画 | GPU（WebGL 2） |
| 音 | Web Audio API |

起動にはNode.js 22.12以降と、WebGL 2対応のブラウザーを使用する。計算、描画、音の処理はブラウザー内で行う。

### メモリの目安

| 内容 | メモリ |
| --- | --- |
| 一つの場の複素振幅 | 約0.40 MiB |
| 主な計算用配列 | 約2.9 MiB＋種一つにつき約0.40 MiB |
| 1920×1080の残光用画像2枚 | 約15.8 MiB |
| 3840×2160の残光用画像2枚 | 約63.3 MiB |

上記は現在の実装から計算した値であり、ブラウザー全体の使用量は別途加わる。残光用画像の数値は描画時の解像度に対する値である。

種の数や解像度が増えると、必要な計算資源も増える。1ステップは185 ms、描画は最大60 fpsを目標としている。実際に使用するPCと画面で確認する。

## 起動方法

```sh
npm ci
npm run dev
```

[localhost:5174](http://localhost:5174/) を開く。操作は[README](../README.md)を参照。

## ビルド・動作確認

```sh
npm run check
npm run preview
```

[localhost:4174](http://localhost:4174/) でビルド後の画面を確認する。`dist/`の内容を静的サーバーで配信できる。GitHub Actionsではテストとビルドを行う。

## 使用時の確認

- タイトルを押した後、次のクリックで種を置く。
- 種を複数置き、波の広がりと干渉を確認する。
- それぞれの波が100ステップ後から徐々に薄くなることを確認する。
- 音量、全画面表示、ドラッグ、長押しの動作を確認する。
- 展示で想定する時間、連続して動かして確認する。

別のタブを開いている間は進行を休止する。ページを再読み込みすると初期状態に戻る。
