# 数理と実装

[READMEへ戻る](../README.md)

本資料は、現在の[計算処理](../src/main.ts)と[描画処理](../src/renderer.ts)に対応します。量子ウォークの演算、入力による状態更新、光景への変換を分けて記述します。

## 1. 格子と状態

位置は161×161の格子、内部状態は0と1の二つです。

```math
|\Psi(t)\rangle=\sum_{x,y}\sum_{c=0}^{1}\psi_c(x,y,t)|x,y,c\rangle
```

各位置の二つの複素数を、四つの`Float32Array`（`ar`, `ai`, `br`, `bi`）で保持します。位置には周期境界を使い、端を越えた成分は反対側へ移ります。

```math
P_t(x,y)=|\psi_0(x,y,t)|^2+|\psi_1(x,y,t)|^2
```

位置の確率には二つの内部状態の絶対値二乗を加えます。位相関係による干渉項は、次のコイン演算で各成分へ振り分けられます。

## 2. 一つの量子ステップ

```math
U_t=S_y C_y\Phi_t S_x C_x,\qquad
|\Psi(t+1)\rangle=U_t|\Psi(t)\rangle
```

右から順に作用します。`C_x`と`C_y`には同じHadamard演算を使います。

| 順番 | 演算 | 関数 |
| --- | --- | --- |
| 1 | 二つの振幅を混ぜる | `applyCoin()` |
| 2 | x方向へ分けて移動する | `shiftX()` |
| 3 | 位置ごとに位相を回転させる | `updatePhaseField()`, `applyPhase()` |
| 4 | 二つの振幅を再び混ぜる | `applyCoin()` |
| 5 | y方向へ分けて移動する | `shiftY()` |

### コイン演算

```math
\begin{pmatrix}\psi'_0\\\psi'_1\end{pmatrix}
=\frac{1}{\sqrt{2}}
\begin{pmatrix}1&1\\1&-1\end{pmatrix}
\begin{pmatrix}\psi_0\\\psi_1\end{pmatrix}
```

例えば0成分の演算後の確率は、

```math
|\psi'_0|^2=\frac{P}{2}+\operatorname{Re}(\psi_0\psi_1^*)
```

となります。1成分では同じ干渉項が引かれます。二つの成分を合計した位置確率は、このコイン演算の前後で保存されます。両成分は続く移動で別の位置へ運ばれます。

### 条件付き移動

```math
S_x|x,y,0\rangle=|x-1,y,0\rangle,\qquad
S_x|x,y,1\rangle=|x+1,y,1\rangle
```

```math
S_y|x,y,0\rangle=|x,y-1,0\rangle,\qquad
S_y|x,y,1\rangle=|x,y+1,1\rangle
```

座標演算は161を法として行います。

### 位相回転

```math
\Phi_t(x,y)=
\begin{pmatrix}e^{i\phi_t(x,y)}&0\\0&e^{-i\phi_t(x,y)}\end{pmatrix}
```

二つの成分の大きさを保ち、位相を逆方向へ回転させます。ドラッグの入力は`phaseMemory`へ蓄え、`phaseField`へ徐々に反映します。これに滑らかな背景位相を加えます。背景位相の係数は0.105と0.08です。

各演算はユニタリです。外部入力・波の削除が入らない時間発展では、全確率を数値誤差の範囲で保存します。実装は20ステップごとに再正規化し、浮動小数点誤差を補正します。

## 3. タネと入力

### タネの準備

実装のタネは、選択位置の近傍へ小さく広がるガウス形の振幅です。

```math
|\Psi_{\mathrm{seed}}\rangle=
\sum_{x,y}g(x-x_0,y-y_0)|x,y\rangle\otimes
\frac{|0\rangle+e^{i\theta}|1\rangle}{\sqrt{2}}
```

`g`は振幅として正規化します。実装では半径パラメータ2.1、各軸±5格子の範囲を使います。`θ`は操作位置から決まります。

すでに`k`個のタネがある場合、既存状態と新しいタネを次の比率で加え、全体を再正規化します。

```math
|\Psi_{\mathrm{new}}\rangle\propto
\sqrt{\frac{k}{k+1}}|\Psi_{\mathrm{old}}\rangle+
\frac{1}{\sqrt{k+1}}|\Psi_{\mathrm{seed}}\rangle
```

加算するのは複素振幅です。異なるタネの寄与も、同じ場の中で干渉します。

### 長押し

`collapse()`は位置確率から一点をサンプリングし、その近傍へ新しいタネを準備します。これはBorn則を使った位置選択と、作品用の状態再準備を組み合わせた入力です。

## 4. タネごとの寿命

タネごとの寄与`ψ^(j)`を別々に保持し、同じ演算子で時間発展させます。線形性により、その和は合成状態と一致します。ここでの分離は、描画の寿命を管理するためのデータ構造です。

タネ`j`の年齢を`a_j`とし、100〜180ステップの間で表示重みを滑らかに減らします。

```math
w(a)=\begin{cases}
1 & a\leq100\\
1-3u^2+2u^3,\quad u=(a-100)/80 & 100<a<180\\
0 & a\geq180
\end{cases}
```

表示用の振幅には、確率に対する重みの平方根を掛けて合成します。

```math
\widetilde\psi_c(x,y)=\sum_j\sqrt{w(a_j)}\,\psi_c^{(j)}(x,y),\qquad
\widetilde P=|\widetilde\psi_0|^2+|\widetilde\psi_1|^2
```

この合成にもタネ間の干渉が含まれます。表示用状態のノルムには1という制約を設けていません。180ステップに達した寄与は計算対象からも取り除き、残った合成状態を再正規化します。タネの追加、サンプリング、期限切れの削除は作品側の外部更新です。

フェードは造形上の時間設計であり、物理的なデコヒーレンスのモデルとは区別します。関連関数は`waveOpacity()`、`buildDisplayState()`、`pruneExpiredWaves()`です。

## 5. 光景への変換

### 光と色

明るさのもとには表示用確率を使います。

```math
L=\left(1-e^{-3.8E\widetilde P}\right)^{0.66}
```

`E`は露光の調整値です。新しいタネの追加による一様な振幅縮小を補償し、以前の波の光量を保ちます。GPUでは発光と残光を重ね、最終的な色へ変換します。

色は二つの表示用振幅の相対位相を基本とします。

```math
\Delta\phi=\arg(\widetilde\psi_0\widetilde\psi_1^*)
```

同じ向きの振幅がある地点を、そのまま最も明るくする規則ではありません。コイン演算で成分ごとの確率が変わり、移動後の分布が光景へ現れます。

### 花

花の候補を選ぶため、コイン演算時の干渉項の絶対値を使います。

```math
I(x,y)=\sum_{C_x,C_y}\left|2\operatorname{Re}(\psi_0\psi_1^*)\right|,\qquad
M_t=0.88M_{t-1}+0.12I_t
```

和は、それぞれのコイン演算直前の値を、その時点の位置で蓄積することを表します。次の条件を3ステップ以上満たした局所ピークを候補にします。

- 位置確率が場全体の最大値の1%以上
- 干渉の履歴`M`が場全体の最大値の15%以上

既存の花との距離も使って候補を選び、過密を抑えます。花の位置選択は同じ状態履歴から同じ結果を返します。干渉項には強め合いと打ち消し合いの両方を含み、花は干渉活動の持続を造形へ変換したものです。花弁の形や寿命は描画上の設計です。

### 流線・空洞・残光

細い流線には近隣の複素振幅から得る方向を使います。これは造形のための流れで、離散量子ウォークの厳密な保存電流とは区別します。流線の初期配置などには乱数が含まれます。

空洞は周囲との確率差から抽出し、残光は過去の描画をGPUで減衰させながら重ねます。これらは、計算結果の見え方を整える可視化の処理です。
