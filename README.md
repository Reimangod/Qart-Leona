# Qart：量子ウォークが描く波動模様

Qartは、量子ウォークが生み出す複素振幅の大きさと位相を、時間とともに育つ光景として可視化する作品です。

画面をタップすると、その場所に一つの「タネ」が置かれます。タネから二つの振幅が格子上へ広がり、重なり、強め合い、打ち消し合います。その計算結果が、青緑と金の波、細い軌跡、花として現れます。

## 量子ウォーク

作品は161×161の格子上で、次の1ステップを繰り返します。

$$
|\Psi(t+1)\rangle = S_y C_y \Phi_t S_x C_x |\Psi(t)\rangle
$$

- $C_x, C_y$：二つの複素振幅を混ぜ、干渉を起こす
- $S_x, S_y$：内部状態に応じて、振幅を反対方向へ移動させる
- $\Phi_t$：場所ごとに位相を回転させ、次の干渉を変える

各地点の明るさのもとになる確率は、二つの振幅の絶対値二乗の和です。

$$
P_t(x,y)=|\psi_0(x,y,t)|^2+|\psi_1(x,y,t)|^2
$$

明るさは確率、色は位相関係、花は強い干渉が数ステップ続いた地点に対応します。新しいタネを置いても以前の波は保たれ、各タネの波は100ステップ後から個別に薄くなり、180ステップで消えます。

## 操作

起動時にタイトルをタップすると作品画面へ移ります。最初のタップはタイトルを閉じるだけで、タネは次のタップから置かれます。

- クリック／タップ：タネを追加
- ドラッグ：波の位相に触れる
- 長押し：確率に応じた場所を選び、そこから再開
- `R`：リセット
- `F`：全画面
- `M`：音の切り替え
- `S`：画像を保存

音は最初の作品操作後に始まります。別のタブを見ている間は進行を休止します。

## 起動

Node.js 22.12以降と、WebGL 2対応のブラウザーを使用します。

```sh
npm ci
npm run dev
```

[http://localhost:5174/](http://localhost:5174/) を開いてください。

## 計算と描画

現在の版は量子コンピューター実機ではなく、量子ウォークの数理モデルをブラウザー内のCPUでリアルタイムにシミュレーションします。161×161地点に二つずつ、約5.2万個の複素振幅を保持します。描画にはWebGL 2を使用します。

```sh
npm test
npm run build
npm run preview
```

`dist/`を静的サイトとして配信できます。
