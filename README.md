# Qart：量子ウォークが描く波動模様

[![CI](https://github.com/Reimangod/Qart-Leona/actions/workflows/ci.yml/badge.svg)](https://github.com/Reimangod/Qart-Leona/actions/workflows/ci.yml)

## 概要

Qartは、量子計算の代表的アルゴリズムである量子ウォークが生み出す可能性の波（複素振幅の大きさと位相）を、時間とともに変化する光景として立ち上げる仕組みである。

観客や周囲の環境がその波の初期状態や位相に働きかけ、その変化が干渉を通して風景として現れる。さらに、この波を光や粒子、素材の運動へ接続し、計算と物質が互いに影響しながら変化し続ける空間へ展開することを目指す。

## 量子ウォークとQart

Qartで用いる量子ウォークは、格子上に置かれた一つの種から始まる。そこから複素振幅が広がり、重なり、干渉しながら模様をつくっていく。

Qartでは、この最初の種や位相を来場者の動きや周囲の環境によって変化させる。人が種を蒔き、その後の波の広がりが光景として育っていく構造を目指す。

現在のブラウザー版では、クリックとドラッグを入力としている。

量子ウォークの1ステップでは、各格子点にある二つの振幅に対して、次の操作を順番に行う。

1. 二つの振幅を足し引きする。$C_x$
2. 振幅をx方向へ移動させる。$S_x$
3. 場所ごとに位相を変える。$\Phi_t$
4. もう一度二つの振幅を足し引きする。$C_y$
5. 振幅をy方向へ移動させる。$S_y$

```math
|\Psi(t+1)\rangle=S_y C_y\Phi_t S_x C_x|\Psi(t)\rangle
```

つまり、「干渉させる → 移動させる → 位相を変える」ことを繰り返すことで、波が格子全体へ広がり、複雑な干渉模様が生まれる。

## 物化に向けて

Qartでは、量子ウォークが生み出す複素振幅の大きさ・位相・干渉の時間変化を、画面上の可視化だけで終わらせず、光や粒子、素材の運動として実空間に立ち上げることを目指したい。

つまり、目に見えない計算内部の「波」を、知覚できる物理現象へ変換する。方向性としては、Pixie Dustやnullの木漏れ日のように、波やデジタルな情報をスクリーンの外へ開き、空間そのものの光景として物化することを考えている。

## 計算資源

現在のブラウザー版では、量子ウォークの数理モデルを古典計算機上でリアルタイムにシミュレーションしている。

Qartの現在の161×161格子では、各地点に二つの複素振幅を保持するため、約5.2万個の複素振幅を逐次更新する。計算はCPU、描画はWebGL 2を使うGPUで行う。

## 起動方法

Node.js 22.12以降と、WebGL 2対応のブラウザーを使用する。

```sh
git clone https://github.com/Reimangod/Qart-Leona.git
cd Qart-Leona
npm ci
npm run dev
```

[localhost:5174](http://localhost:5174/) を開く。タイトルを押すと作品の画面に移り、次のクリックで種を置く。

| 操作 | 内容 |
| --- | --- |
| クリック／タップ | 種を置く |
| ドラッグ | 場所ごとに位相を変える |
| 長押し | 確率に応じて位置を選び、その近くから再開する |
| `F` / `M` | 全画面 / 音の切り替え |
| `R` / `S` | リセット / 画像の保存 |

音は、作品の画面で最初に操作したときに始まる。それぞれの種から広がる波は100ステップを超えると徐々に薄くなり、180ステップで消える。
