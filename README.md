# Qart — 存在しなかった庭

161×161の量子ウォークから育つ、リアルタイムのジェネラティブアート。
クリックした場所から始まり、自動で進みます。画面には作品だけを表示します。

## 起動

Node.js 22.12以降と、WebGL 2対応のブラウザーを使用します。

```sh
npm ci
npm run dev
```

[http://localhost:5174/](http://localhost:5174/) を開き、好きな場所をクリックしてください。
最初はタネのない暗い画面です。

## 操作

- クリック／タップ：タネを追加
- ドラッグ：波の位相に触れる
- 長押し：確率に応じた場所を選び、そこから再開
- `R`：リセット、`F`：全画面、`M`：音の切り替え、`S`：画像を保存

音は最初の操作後に始まります。別のタブを見ている間は進行を休止します。

## 確認・ビルド

```sh
npm test
npm run build
npm run preview
```

`dist/` を静的サイトとして配信できます。計算はブラウザー内のCPU、描画はWebGL 2で行います。
